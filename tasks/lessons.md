# Lessons

- **Japanese accents must translate the name, not the topic.** Dave corrected
  the site-name transliteration: イーサリアムへ ("to Ethereum") → イーサの中へ
  ("into the Ether"). When using Japanese (or any language) as brand
  decoration, translate the actual name/phrase literally and check the
  grammar — don't substitute a related keyword. Same rule applies to the
  per-page kana accents: they should mean what the heading means.
